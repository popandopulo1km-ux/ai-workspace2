ПРОИСХОЖДЕНИЕ
Исходники приложения получены непосредственно из /opt/app рабочего сервера через VibeCode от пользователя vibeapp (uid999). После получения SHA256 повторно сверены с сервером: файлы не изменились за время сборки.
PHP-файлы прочитаны из штатного редактора файлов действующего Битрикса без сохранения. Их хэши относятся к полученному UTF-8 тексту редактора, а не к независимому чтению байтов файловой системы коробки.
Код и package.json сохранены без исправлений. Рабочее приложение, CRM и службы не изменялись.

СРЕДА И ПРОВЕРКА
Рабочая среда: Node.js v20.20.2, Python 3.12.3, Linux, пользователь службы vibeapp.
package.json не объявляет сторонних npm-зависимостей. Python использует стандартную библиотеку, включая sqlite3.
Для статической проверки JS: node --check имя-файла.js (или .mjs). Это не запускает приложение.
PHP-код требует коробку Bitrix и её модули. Его можно проверить php -l в установленном PHP, но это не проверка интеграции с CRM.
Важно: npm test и npm run check ссылаются на test.mjs, которого нет в текущем /opt/app. Набор исторических локальных тестов в этот снимок не подмешан.
Проверка синтаксиса не означает, что выполнены функциональные или безопасностные тесты. В рамках выгрузки они не запускались.

ЛОКАЛЬНЫЙ ЗАПУСК
Это снимок исходников для аудита, не автономная копия CRM. npm start запускает server.js, но без тестовой интеграции и данных бизнес-сценарии не воспроизводятся полностью.
Нужны отдельные тестовые настройки VIBE_APP_KEY, VIBE_API_BASE, BITRIX_PORTAL_URL, APP_PUBLIC_URL, при необходимости PORT и HISTORY_PYTHON; для защищённого сохранения — тестовый ключ PASSPORT_GUARD_SIGNING_KEY и соответствующий публичный ключ в тестовом guard.
Часть путей данных по умолчанию указывает на /opt/app/data и /opt/app/purchase-history. Состав ожидаемых файлов определяется исходниками; реальные данные намеренно не вложены.
Не запускайте установщик wm-passport-install.php и таймеры на рабочей CRM ради проверки архива: они выполняют изменения. Для динамических проверок используйте изолированный стенд и синтетические данные.
